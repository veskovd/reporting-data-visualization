# Tools for Reporting and Data Visualization

Academic project focused on data analysis, visualization and business reporting.

The project covered three main areas:

- SQL-based data analysis
- Interactive data visualization using Power BI
- Development of structured business reports

## SQL Analysis

SQL was used to analyze sales, orders, customers and products.

The analysis included:

- joins across multiple tables
- filtering and aggregation
- ranking functions
- window functions
- ROLLUP
- PIVOT
- SQL views

## Power BI

Power BI was used to create interactive analyses and dashboards focused on sales and product data.

The dashboards supported exploration of business performance through different dimensions and filters.

## Business Reporting

Structured reports were created for different business requirements, including:

- order lists
- orders grouped by customer
- total order value by customer and year
- graphical summaries
- analysis of top customers by sales value

## Technologies

SQL • Power BI • Microsoft Report Builder
